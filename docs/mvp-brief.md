# Resus MVP
Native local macOS study app, MIT licensed, empty remote https://github.com/kenyounot123/resus.git. Swift 6.4 and Xcode27 available on arm64 Mac. Minimum macOS14 preferred. No backend. Rich text note writing with headings/bold/italic/lists, undo/autosave. Local courses and notes. BYOK provider online generation. Clarify shorthand explicitly, approve draft cards, offline recall/rating and written practice. Exact source excerpts per card. Changed notes flag cards and preserve approved answers. Keychain for keys. Backup export/import. Refreshing warm neutral/teal UI matching Paper concepts. No hosted web app. Downloadable app zip/DMG and reproducible scripts. Need real UI exercise and meaningful tests. Real API must not be claimed verified without credentials. Never embed keys or hidden fixture in shipped app.

Design sources in docs/design/write.png, clarify.png, study.png, and changed-notes.png. These are mock screenshots. Architecture candidates requested. Produce types/signatures, ownership and data invariants before implementation. Compare Codable atomic local archive with SwiftData. Prefer reliable backup/recovery, explicit draft/approved status, stable note/card IDs and source snapshots, isolated UI verification folder, pure lifecycle tests, transparent networking. No user checkpoint needed. Plain domain nouns Note, Course, Card, Clarification, Library pass naming tests. Alternative Lecture overly confines notes, StudyItem vague. App remains usable offline and without key via manual cards.
