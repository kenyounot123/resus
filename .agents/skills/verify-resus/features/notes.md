# Notes

## Sub-features

Create and edit course notes with native rich text.

## How to get to it (user POV)

Use New note in the toolbar or File menu. New course is the plus beside Courses. Import is available in the toolbar and File menu.

## Driving it with cua_repl

Edit Note title. Paste into Note body. Select text, use Bold, Heading, and list controls. Switch notes and restart. Inspect text and RTF in the isolated archive. Import a UTF-8 text file and an RTF file.

## Gotchas

The editor stores canonical RTF text. List marker presentation can differ from plain text. Formatting alone must not pause cards.
