# Cards

## Sub-features

Create manual cards or provider drafts. Clarify shorthand, inspect sources, and approve explicitly.

## How to get to it (user POV)

Add card and Create cards are below the selected note. Settings contains the provider key. Cards is the note tab.

## Driving it with cua_repl

Drive the loopback fixture through Settings and Create cards. Confirm meanings or Exclude this line. Create drafts and approve. Add a manual card with an exact source quote. Change a note, verify cards pause, then use Review changes and Approve card. Inspect the saved original source before re-review.

## Gotchas

New drafts cannot be studied. Any text change pauses every older-source card. Generation accepts source snapshots only if the note stayed unchanged. Real providers require billed API keys.
